Ballonflugbuch Web-App
Installation auf GitHub Pages
ZIP entpacken.
Alle Dateien in das Hauptverzeichnis eines GitHub-Repositorys laden.
Settings > Pages > Deploy from a branch wählen.
Branch main und Ordner / (root) auswählen.
GPS funktioniert nur über HTTPS oder localhost. Standortfreigabe ist erforderlich. Karten und Wetter benötigen Internet. Die Fahrten werden lokal im Browser gespeichert.
Funktionen
Live-GPS, Standard-/Satelliten-/Topokarte, automatische Positionsverfolgung, Fahrtdaten, Höhenprofil, Flugbuch, Statistik, Wetter, Markierungen, Foto-Vormerkung, GPX-Import/Export, KML-Export, JSON-Sicherung, PWA und Wake Lock.
Die App ist kein zertifiziertes Navigationsinstrument.
